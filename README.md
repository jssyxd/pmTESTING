# pmTESTING - ZSPD Temperature Bias Correction Archive

This repository permanently stores daily structured reports, F2 correction reports, and final decision reports for ZSPD (Shanghai Pudong Airport, 31.145°N, 121.793°E) 2m temperature prediction and bias correction.

## Structure
- /data/ : Raw daily observation and model data
- /reports/structured/ : Structured reports with detailed basis
- /reports/f2_correction/ : F2 correction reports with reasoning
- /reports/final_decision/ : Final decision reports
